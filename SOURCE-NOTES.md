# Source Notes

## API Snapshot

The API reference was collected from [GTPSCloud documentation](https://dash.gtps.cloud/docs) on November 16, 2026. API identifiers and source signatures are retained. This community learning pack is not an official SDK.

## Public Reference Scripts

The owner supplied and confirmed normal operation of the following scripts:

- [Find-Script.lua](reference/Find-Script.lua): in-game item search, dialogs, restrictions, and inventory operations.
- [Help-Script.lua](reference/Help-Script.lua): role-based command discovery and help dialogs.

Their Lua source text is preserved with LF line endings. Confirmation of overall operation does not establish independent testing of every branch.

Private Discord administrative source and the derived administrative status example are excluded at the owner's request. Generic API conventions may still be documented without publishing private feature implementations.

## Generated Adaptations

The three public standalone examples are simplified learning material. Their syntax and selected behaviors were checked locally using Lua 5.4 and mocked bindings. They have not been run against the owner's live server.

The large Markdown catalog preserves documentation forms, including conflicting utility conventions. Runtime notes and explicit owner corrections take priority for this project.

Only learning material and explicitly public examples belong in this repository. Do not add private administrative scripts, uploaded attachments, credentials, local tool state, or scratch files.
